# English School Platform — Student Dashboard

Адаптивный интерактивный прототип личного кабинета ученика для онлайн-школы английского языка.

###  Решаемая проблема (Бизнес-контекст)
Проект разработан как альтернатива отправке домашних заданий в формате PDF. Платформа позволяет студентам выполнять аудирование, интерактивные грамматические тесты и писать эссе прямо в интерфейсе кабинета с возможностью сохранения прогресса.

---

##  Стек технологий

*   **Сборщик проекта:** [Vite](https://vite.dev) (оптимизированная сборка)
*   **Стили:** HTML5, CSS3 / SCSS (использование кастомных CSS-переменных)
*   **Язык:** Чистый Vanilla JS (ES6+)
*   **Анимации:** [GSAP (GreenSock)](https://gsap.com)
*   **Шрифты и иконки:** Google Fonts (Inter), SVG

---

##  Ключевые возможности (в разработке)

1. **Hero Section:** Главный экран личного кабинета в минималистичном стиле.
2. **Dark/Light Theme**: Переключение между светлой и тёмной темами.
3. **PWA Support**: Поддержка Progressive Web App. Можно установить на смартфон как отдельное приложение.
4. **3D Flip Cards:** Интерактивный тренажер для запоминания слов. (в разработке)
5. **Student Dashboard:** Баланс оставшихся уроков, календарь предстоящих занятий и архив видеозаписей прошлых уроков. (в разработке)
6. **Interactive Homework (Вместо PDF):**
   * Встроенный плеер для аудирования. (в разработке)
   * Тест с моментальной проверкой ответов. (в разработке)
   * Поле для написания эссе. (в разработке)
7. **Teacher Chat Simulation**: Интерактивный чат с преподавателем прямо внутри интерфейса для оперативной связи. (в разработке)

##  Быстрый старт (Local Development)

Для запуска проекта на локальной машине необходима установленная среда **Node.js** (LTS-версия).

1. Установите зависимости проекта:
   ```bash
   npm install
   ```

2. Запустите локальный сервер разработчика:
   ```bash
   npm run dev
   ```

3. Откройте проект в браузере по адресу, указанному в терминале (обычно `http://localhost:5173/`).
