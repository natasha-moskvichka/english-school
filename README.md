# 🇧🇷 English School MVP

Интерактивный прототип веб-интерфейса и личного кабинета для онлайн-школы английского языка. Проект разработан как независимый MVP с целью демонстрации современных возможностей фронтенд-разработки, интерактивных UI-компонентов и плавной анимации.

---

## 🛠️ Стек технологий

*   **Сборщик проекта:** [Vite](https://vite.dev) (оптимизированная сборка)
*   **Архитектура стилей:** SCSS
*   **Анимации:** [GSAP (GreenSock)](https://gsap.com)
*   **Шрифты и иконки:** Google Fonts (Inter / Montserrat), SVG

---

## 🔮 Основные модули и фичи (В разработке)

1.  **Hero Section:** Главный экран в эстетичном, минималистичном стиле с мягкими ховерами кнопок.
2.  **3D Flip Cards:** Интерактивный тренажер для запоминания слов на чистом CSS/SCSS (карточки плавно переворачиваются при наведении).
3.  **Student Dashboard:** Адаптивный прототип личного кабинета ученика (баланс уроков, календарь, блок домашних заданий с возможностью прикрепления файлов).

---

## 🚀 Быстрый старт (Local Development)

Для запуска проекта на локальной машине необходима установленная среда **Node.js** (LTS-версия).

1. Установите зависимости проекта:
   ```bash
   npm install
   ```

2. Запустите локальный сервер разработчика:
   ```bash
   npm run dev
   ```

3. Откройте проект в браузере по адресу, указанному в терминале (обычно `http://localhost:5173/`).

---

## 📦 Сборка для продакшна

Для компиляции, оптимизации изображений и сборки легковесного архива для бэкенда выполните команду:
```bash
npm run build
```
Готовые файлы для передачи разработчикам появятся в папке `/dist`.
